# 莱茵生命档案终端风格

参考图：[assets/archive-reference.jpg](assets/archive-reference.jpg)。这是 [RhineLabUI](https://github.com/LBEILC/RhineLabUI) 对《明日方舟》「莱茵生命：访问」终端的非官方复刻截图，取其画面语言作为参考。生成前查看这张图；若图像工具支持参考图输入，将它作为视觉参考传入。

## 核心视觉

- **画面结构**：优先使用 16:9 横版。大量乳白色档案盒或薄板沿纵深排成密集、平行的斜向阵列，近处被画面裁切，远处逐渐变小；留出中右区域承载主要文件信息。让重复的实体阵列承担视觉重量，而不是用人物或复杂场景填满画面。
- **色彩与光线**：暖白、象牙白、浅灰为主，文字用近黑色；只在少量仪器细节使用低饱和黄铜或灰蓝点缀。柔和漫射光、轻微纸张与磨砂塑料质感、浅而真实的接触阴影。避免强霓虹、深色赛博朋克背景和高饱和渐变。
- **版式**：左上角放紧凑的机构名称与副标题；中右用醒目的文件编号或档案标题建立焦点；四角分布克制的页码、权限、栏目与操作提示。使用粗细对比明确的无衬线字体、英文大写短标签、细线和小刻度。大块留白与细密信息并存。
- **气质**：冷静、精密、制度化，像真实的科研资料库或分析系统。画面可带轻微扫描纹理，但保持干净、可读。

## 生成方式

1. 先把用户的主题、机构名称、文件主题、输出比例和用途代入画面。未指定时，采用虚构科研机构与简短占位信息，并以 16:9 制作一张图。
2. 用可用的图像生成工具生成画面，并同时给出参考图与上述构图、材质、排版要求。要求“借鉴视觉语言，重新组织档案阵列、编号和文字”，避免逐像素复刻原图。
3. 检查成品是否具备档案阵列、暖白低对比材质、黑色层级文字和足够留白。若文字需要准确可读，优先用可靠的排版工具完成文字层；不要把生成模型的乱码当作成品。
4. 交付生成图片，并简要说明采用了哪些参考特征。只有用户明确要求《明日方舟》或莱茵生命标识时，才在成品中使用相关名称和标志。

## 可直接改写的图像提示词

> 为「{主题或机构}」制作一张 16:9 科研档案终端概念图。参考所附档案阵列图片的视觉语言：大量乳白色半透明薄档案盒沿斜向透视排列，层层延伸至远处；暖白背景、柔和漫射光、细微磨砂材质与浅灰阴影。左上是紧凑黑色机构字标与小号副标题，中右是醒目的文件编号「{编号}」和简短档案标题，四角散布克制的英文大写元数据、页码、细线与小刻度。保持大面积留白和准确的视觉层级。画面无人物、无霓虹、无深色背景，重新设计内容与布局，不复刻参考图中的原有文字。
