这是本站的第一个项目：一个同时展示作品与文章的个人网站。

## 目标

- 让来访者快速了解作品与写作主题。
- 用 Markdown 写文章，降低日常维护成本。
- 在网页后台编辑 Markdown 文章，并用 SQLite 保存文章、账号和评论。

后续可以在这里补充设计过程、截图、遇到的问题和最终成果。准备好真实作品后，复制此文件并修改内容即可添加新的作品。
