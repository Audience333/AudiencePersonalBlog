## 风格线索

- **基础视觉**：白、黑与偏暖的浅灰为底，关键处使用橙色或低饱和色点缀。
- **信息组织**：英文大写机构名、档案编号、细线分区、小字号字段形成“实验记录”感。
- **图形语言**：双环标志、圆环和十字、仪器刻度、模块化卡片。
- **材质与空间**：半透明玻璃、磨砂外壳、档案盒阵列与实验室设备。

后三张是创作者对《明日方舟》特别映像「莱茵生命：访问」的**非官方复刻**，不是游戏官方界面截图。项目页面载有作者的来源与权利说明。
