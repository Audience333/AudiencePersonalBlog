正文
本站既可以构建成纯静态文件，也可以跑自带的 Node 服务：两条路各自适合什么场景。

## 纯静态

丢给任意托管即可，PWA 离线可用，但没有后台。内容更新要走「改文件 → 重新构建 → 重新部署」的完整流程。

## Node 服务

多一个管理后台和运行时数据，适合想随时改内容的阶段。本站目前就是这个形态：后台保存档案，前台通过 API 读取，改动即时生效。

## 两者兼得

前端用「API 优先、打包快照兜底」兼容两者：运行时优先请求 `/api/records`，拿不到就退回构建时打包的 JSON 快照，离线也能浏览上次构建的内容。

个人站点的正确答案是：先跑起来，再按需要换形态。
